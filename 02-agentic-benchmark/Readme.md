# Introduction

Here I'm using `terminal-bench` for model agentic capability benchmarking.

# Naming Convention
Benchmark result file naming convention `${BENCHMARK_NAME}_${MODEL_NAME}.`.

Take 

- benchmark: `terminal-bench-2`
- model: `deepseek-v4-pro`

ask an example. \
The result file name will be `terminal-bench-2_deepseek-v4-pro.md`.
